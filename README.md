# TP-Link CT3CY 电信运营商定制版摄像头刷公版固件指南

> 本项目基于恩山论坛帖子整理：[原帖地址](https://www.right.com.cn/forum/thread-8494397-1-1.html)

闲鱼上大量的二手 **TP-Link CT3CY** 运营商定制摄像头（300万像素带云台），性价比极高。但原厂固件嫁割严重（小翼管家卡顿、广告多、无 ONVIF/RTSP、无 Web 页面）。

经外观与配置对比，CT3CY 与官方 **TL-IPC43AN-4** 硬件高度一致。通过刷入官方公版固件，可完美解锁 Web 管理、ONVIF、RTSP 拉流及本地 NVR 接入。

---

### 🛠️ 硬件信息 (CT3CY V2.0)
* *CPU*：SSC325
* *传感器*：SC3335
* *Flash*：8MB
* *网口*：带网口（方便调试）
* *适配官方固件*：`TL-IPC43AN-4 V4.0` (支持 V1.0/V2.0/V4.0)

### ⚙️ 刷机步骤
> 💡 提示：上述步骤较繁琐，可将固件和需求交给 AI 自动完成打包。

1. 备份原机 **8MB** 编程器固件。
2. 从官网下载 `TL-IPC43AN-4 V4.0 (如 20211105_1.0.28)` 升级固件。
3. 从升级固件的 `0x800` 处截取 `0x7A0000` 字节，写入 Flash 的 `0x60000`。
4. 从升级固件末尾 ISP 数据区的 `0x7B1084` 处截取 `0x58F0` 字节，写入 Flash 的 `0x30000`。
5. 修改编程器备份的工厂分区（`0x2D800 – 0x30000`）：
  * 将型号和版本号改为 `TL-IPC43AN-4` 和 `4.0`。
  * *重新计算 MD5** 后写回 Flash。
6. 刷机完成后，**务必恢复一次出厂设置**。

### ✨ 功能流量与使用说明

* *本地流媒体**：Web 页面一切正常，支持 ONVIF 和 RTSP 正常拉流，可完美对接本地 NVR。
* *TP-LINK 物联 APP**：
  * *本地模式**：不登录账号，可直接局域网发现并添加设备，一切正常。
  * *运程模式**：直接登录账号添加会失败（因服务器无该设备认证）。
  * *完美绕过方法**: 在摄像头 **Web 管理页面 -> 云服务** 中，填写云账号和密码进行绑定，绑定后即可在 APP 远程查看。
* *实测功能**：公网 P2P 远程连�%�、人形识别、移动侦流均可正常使用。
